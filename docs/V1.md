# V1 implementation contract

## Goal

Validate whether the Pixel 10 Pro can observe enough data from Deliveroo, Uber Eats and Just Eat notifications to make a useful local recommendation before an offer expires.

## Confirmed Uber reference format

A real Uber offer notification supplied during development showed:

```
Delivery • £7.32
19 min (3.9 mi) away
```

The parser now has a regression test for this exact visible format.

Important: the reference screenshot was captured on iOS. The Pixel/Android payload still needs a live field test to confirm that Uber exposes the same title/text fields through Android NotificationListenerService.

## Bike configuration

- configured maximum bike speed: **19 mph**
- the scorer calculates required average speed from each displayed distance/time pair
- if a displayed estimate would require an average speed above 19 mph, the estimate is flagged as physically implausible for this bike
- actual learned delivery speed should later replace simple assumptions where appropriate

For the £7.32 / 3.9 mi / 19 min reference offer:

- ~£1.88/mile
- ~£23.12/hour from the displayed estimate
- ~12.32 mph required average speed
- ~12.32 min theoretical riding floor at a constant 19 mph
- current deterministic score: **90/100 → ACCEPT**

## In scope

- Android NotificationListenerService
- courier package identification
- raw notification capture
- pay / distance / time parsing where exposed
- deterministic local scoring
- 19 mph bike-cap feasibility check
- SQLite logging
- recommendation notifications
- optional VESC telemetry interface
- no external server dependency

## Out of scope for V1

- automatic Accept/Decline taps
- private API interception
- MITM traffic inspection
- auth/session token extraction
- accessibility scraping of courier UIs
- direct Flipsky BLE decoding before the module/protocol is verified
- live route APIs / traffic
- JEV remote adapter

## Default score thresholds

- minimum £/mile: £1.20
- preferred £/mile: £1.80
- minimum £/hour: £12
- preferred £/hour: £18
- bike reserve target: 4 miles when telemetry is available
- bike maximum speed: 19 mph
